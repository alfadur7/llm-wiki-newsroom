## Overview

Open Source AI is an AI system released under terms that grant users four freedoms — to use, study, modify, and share the system for any purpose without asking permission. The [[OpenSourceInitiative]] codified this in the Open Source AI Definition (OSAID) 1.0, released 2024-10-28, which requires access to three components: data information, complete source code, and model parameters (weights). The definition adapts the 1998 Open Source Definition to machine-learning systems, where the software alone is insufficient to reproduce or modify a model. It is deliberately binary — a system either meets the freedoms or it does not — and is intended in part to curb [[OpenWashing]]. The definition is contested: critics including the [[FreeSoftwareFoundation]] and OSI co-founder Bruce Perens hold that requiring "data information" rather than the [[TrainingData]] itself makes the label hollow, an objection set out in [[open-training-data-requirement|the open-training-data dispute]].
